# Estúdio — instaladores

**Para instalar num PC novo:** baixe e instale o **Estúdio Central**. Ele mostra todos os apps, instala os que você escolher e avisa quando sair versão nova.

➡️ [Baixar o Estúdio Central](https://github.com/Samukaxcn/estudio-lancamentos/releases/download/central-v1.2/Instalar-Estudio-Central-1.2.exe)

Apps: FaceSort, Culling, Bridge, Capas, Sequência, Renomear, Foto, Montagem, Álbum, Ferramentas e Design.

Todas as versões ficam em [Releases](https://github.com/Samukaxcn/estudio-lancamentos/releases). O arquivo `versoes.json` é a lista que o Central lê.
